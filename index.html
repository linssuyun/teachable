雙手方向盤操作技巧

本遊戲為**駕駛座第一人稱視角**。坐在鏡頭前，雙手於胸前做出**握著方向盤**動作：

Class 1 (向左轉)： 雙手向左旋轉，駕駛座方向盤跟著左轉，視角向左避讓。
Class 2 (直線加速)： 雙手平握方向盤，車輛穩定向前行駛。
Class 3 (向右轉)： 雙手向右旋轉，駕駛座方向盤跟著右轉，視角向右避讓。
